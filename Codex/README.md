# Archivos de trabajo de Codex

Esta carpeta reúne el contexto y los archivos auxiliares creados durante la revisión del proyecto.

- `Bitacora/`: cambios narrativos, diálogos revisados y contexto de cada zona terminada. Se conserva en Git.
- `Contexto/`: lore general, personajes, trama principal y criterios globales del juego. Se conserva en Git.
- `Backups/`: copias de seguridad locales. No se sube a GitHub.
- `Herramientas/`: scripts temporales de lectura, diagnóstico e inyección segura. No se sube a GitHub.
- `Registros/`: volcados, comparaciones, capturas y pruebas técnicas. No se sube a GitHub.

Los archivos definitivos del juego permanecen en sus carpetas originales. Cada bloque terminado y validado se publica mediante un commit descriptivo; los experimentos o trabajos incompletos permanecen únicamente en local.
